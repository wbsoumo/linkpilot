Zoom Integration Configuration Guide
  1. Log in to the Zoom App Marketplace.
  2. Click Develop → Build App in the top navigation.
  3. Select OAuth app type.
  4. Copy the Redirect URI shown on the left (https://linkpilot.work/backend/api/external_apps/zoom_callback.php) and paste it into **both** fields in Zoom App console:
    • OAuth Redirect URL
    • OAuth Allow List (Whitelisted URL)
    ⚠️ Crucial: If these do not match Zoom settings exactly, you will get the "Invalid redirect (4,700)" error.
  5. Under **Scopes**, request access to: meeting:write, meeting:write:admin and user:read.
  6. Copy your **Client ID** and **Client Secret** into the fields on the left and click **Save Zoom Credentials**.
  7. Enable **Webhooks (Event Subscriptions)**, copy the **Secret Token** generated, paste it into the **Zoom Webhook Secret Token** field, and configure your webhook URL as `https:///backend/api/external_apps/zoom_callback.php` then click Validate.
